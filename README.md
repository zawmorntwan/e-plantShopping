# 🌿 Paradise Nursery — Shopping Application

Paradise Nursery is an intuitive e-commerce application designed for houseplant enthusiasts to browse, learn about, and purchase a curated collection of indoor and outdoor plants.

---

## ✨ Features

### 1. Landing Page
- **Hero Showcase**: Welcoming introduction highlighting the nursery's mission and plant collections.
- **Get Started Action**: A prominent call-to-action button directing users straight to the Product Listing page.

### 2. Navigation Bar
- Persistent navigation across all main views:
  - **Landing Page**
  - **Product Listing (Plants)**
  - **Shopping Cart** (with a live badge showing total item count)

### 3. Product Listing
- **Category Grouping**: Plants categorized into distinct curated sections:
  - 🌸 **Aromatic Plants** (e.g., Lavender, Jasmine, Mint)
  - 🌿 **Medicinal Plants** (e.g., Aloe Vera, Tulsi/Holy Basil, Neem)
  - *(Easily expandable to additional categories like Air Purifiers, Low Light, etc.)*
- **Plant Cards**:
  - High-quality image thumbnail
  - Plant Name
  - Brief description & care details
  - Unit price
  - **"Add to Cart"** button (with dynamic feedback once added)

### 4. Interactive Shopping Cart
- **Cart Summary**:
  - Itemized plant cards for each unique item added
  - Thumbnail, unit price, and subtotal per plant type
  - Real-time quantity controls: **Increase (+)**, **Decrease (-)**, and **Delete / Remove**
- **Cart Total**: Real-time calculation of total units and order amount.
- **Action Buttons**:
  - **Continue Shopping**: Returns to the plant catalogue to add more items.
  - **Checkout**: Initiates order finalization / checkout summary.
